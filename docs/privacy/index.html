Kebijakan Privasi

Aplikasi: Tren Esports ID · Berlaku sejak 5 Oktober 2026

1. Ringkasan

Tren Esports ID adalah aplikasi otomatisasi yang membuat konten video singkat bertema Mobile Legends: Bang Bang (MLBB) lalu mengunggahnya ke satu akun TikTok milik pemilik aplikasi. Aplikasi ini tidak mengumpulkan, menyimpan, atau menjual data pribadi pengguna.

2. Data yang Dipakai Aplikasi

Aplikasi hanya memakai data berikut, semuanya milik pemilik aplikasi:

  • Kredensial API TikTok (Client Key, Client Secret, refresh token) yang diberikan langsung oleh pemilik aplikasi melalui file .env di komputer lokal dan GitHub Secrets.
  • Konten publik dari kanal YouTube esports untuk menentukan topik yang sedang ramai.
  • Judul tren yang menjadi bahan pembentuk caption.

3. Penggunaan Cookie dan Pelacakan

Tidak ada cookie iklan, tidak ada pelacak pihak ketiga, dan tidak ada analitik pengguna. Halaman ini hanya dokumen statis.

4. Penyimpanan dan Keamanan Token

Token API disimpan pada file .env di komputer pemilik aplikasi (tidak masuk ke repository) dan pada GitHub Actions Secrets di server GitHub. Repository kode bersifat publik namun tidak memuat kredensial apa pun. Token dapat dicabut kapan saja melalui pengaturan developer TikTok.

5. Konten yang Dikirim

Semua video dan caption dibuat otomatis dari informasi publik. Video tidak memuat musik berhak cipta yang diambil dari sumber lain, dan tidak meniru materi berhak cipta milik pihak ketiga. Penulis bertanggung jawab penuh atas konten yang dikirim dari akun miliknya.

6. Kontak

Pertanyaan atau permintaan penghapusan data dapat dikirim ke theahuda@gmail.com.

7. Perubahan Kebijakan

Kebijakan ini dapat diperbarui; tanggal berlaku di atas selalu mencerminkan versi terbaru.
