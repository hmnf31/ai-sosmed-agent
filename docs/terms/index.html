Syarat Penggunaan

Aplikasi: Tren Esports ID · Berlaku sejak 5 Oktober 2026

1. Ruang Lingkup

Syarat ini berlaku ketika aplikasi Tren Esports ID digunakan untuk membuat video bertema Mobile Legends: Bang Bang dan mengunggahnya ke TikTok. Dengan memakai aplikasi ini, Anda menyatakan bahwa Anda memiliki akun TikTok tersebut dan merupakan pemilik sah dari konten yang dikirim.

2. Kewajiban Pengguna

  • Anda bertanggung jawab penuh atas isi caption dan video yang dikirim.
  • Anda dilarang memakai aplikasi ini untuk menipu, melakukan spam, atau melanggar ketentuan TikTok maupun komunitas esports.
  • Anda tidak akan mengunggah materi berhak cipta milik pihak lain, termasuk rekaman pertandingan yang haknya bukan milik Anda.
  • Kredensial API berupa Client Key, Client Secret, dan refresh token bersifat rahasia dan tidak boleh dibagikan.

3. Ketersediaan Layanan

Aplikasi ini diberikan tanpa jaminan. TikTok dapat menolak unggahan, membatasi frekuensi, atau mencabut akses API kapan saja tanpa pemberitahuan. Gangguan sumber data publik seperti YouTube dan OpenRouter dapat membuat satu siklus berjalan memakai daftar topik cadangan.

4. Batasan Tanggung Jawab

Pembuat aplikasi tidak bertanggung jawab atas kerugian yang timbul akibat penolakan unggahan, penangguhan akun, atau isi caption yang dihasilkan model bahasa AI. Pemeriksaan akhir atas caption sebelum dipublikasikan tetap menjadi tanggung jawab Anda.

5. Penghentian Penggunaan

Anda dapat menghentikan penggunaan kapan saja dengan mencabut token di pengaturan developer TikTok, lalu menghapus file .env dan GitHub Secrets.

6. Kontak

Pertanyaan dapat dikirim ke theahuda@gmail.com.
